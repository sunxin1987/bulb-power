# 测小灯泡电功率实验模拟

伏安法测量小灯泡的电功率：电源、开关、滑动变阻器、电流表和小灯泡串联，电压表并联在小灯泡两端。拖动滑动变阻器的滑片，改变小灯泡两端的电压，读出对应的电流，用 P=UI 算出实际功率；电压等于额定电压时小灯泡正常发光，测得额定功率。

在线打开：https://sunxin1987.github.io/bulb-power/

## 能做什么

- **电路模拟**：滑动变阻器滑片可拖，开关可闭合/断开；电压表、电流表指针实时偏转，读数随滑片移动变化。
- **读数与计算**：电压、电流实时显示，P=UI 实时算出实际功率；灯泡亮度随实际功率变化，电压等于额定电压 2.5 V 时正常发光。
- **灯丝烧断**：电压过高（约 3.8 V）会烧断灯丝，电路开路、电流表示数为 0；换上新灯泡后注意实际电压不要超过额定电压的约 1.2 倍。
- **记录表格**：点“记录”把一组电压、电流、功率数据记入表格，方便整理实验数据、分析亮度与功率的关系。
- **离线版**：页首“下载离线版”按钮把本页存成单个 HTML，断网也能打开使用。

## 手机安装

- **Android**：下载 Releases 里的 `bulb-power.apk`，直接安装（WebView 封装，离线可用）。
- **iOS**：下载 Releases 里的 `bulb-power.ipa`（未签名），在 iPhone 上用 [AltStore](https://altstore.io) 打开安装，需配合电脑上的 AltServer；免费账号签名的 App 每 7 天过期，iPhone 与电脑同一 WiFi 且 AltServer 开着时自动续签。

## 说明

本模拟照九年级物理“测量小灯泡的电功率”实验制作：小灯泡额定电压 2.5 V，电压过高（约 3.8 V）会烧断灯丝；灯泡亮度随实际功率变化。示意图为电路模型，表盘读数与真实实验一致。
